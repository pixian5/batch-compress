## 背景与目标

此前图形界面仅通过 `WindowStateService` 持久化窗口几何状态（`window-settings.json`）及通过 `EnclosureConfigService` 外置附件配置（`enclosures.txt`），界面中的语言选择、受控并发度、当前操作页签及压缩/解压常用参数在每次重启后会全部重置。

本批次（批次 40）实现 **安全 GUI 用户偏好持久化（`UserPreferencesService`）**：在重启后记住用户的非敏感、非破坏性界面设置，同时从数据结构与序列化层彻底屏蔽敏感凭证和危险开关。

## 代码改动与安全边界

### 1. 新增 [UserPreferencesService.cs](file:///Users/x/code/compress/Core/Services/UserPreferencesService.cs)

- **存储路径**：与 `WindowStateService` 同目录的用户数据目录 `<ApplicationData>/BatchCompress.Avalonia/user-preferences.json`（不引用 Avalonia 类型，支持通过构造注入临时路径做单元测试）。
- **严格安全排除清单**：仅映射 `OperationTabPreferences` 与 `UserPreferencesSnapshot` 中的安全常规字段；内部序列化 DTO 显式**排除**以下敏感或破坏性字段：
  - `CustomPassword`（防止明文密码落盘）
  - `DeleteSourceAfter`（防止下次打开意外勾选“删除源文件/原归档”）
  - `ShutdownAfterComplete`（防止下次打开意外勾选“完成后关机”）
  - 单次会话路径/清单/结果（`SourcePath`、`SaveFilePath`、`OutputPath`、`SourceFileList`、`TempDirectory`、`PasswordQueryFileName`、`PasswordQueryResult`、`EnclosureList`）。
- **原子写入与边界归一化**：
  - `Save` 先生成同目录随机临时文件 `.tmp`，写入带缩进 JSON 后 `File.Move(..., overwrite: true)` 原子替换，并在 `finally` 兜底清理残留 `.tmp`，捕获所有 IO 异常以避免阻塞关闭。
  - `Load` 与 `Normalize` 将并发度钳制在 `1..16`、操作页签在 `0..1`、压缩级别在 `0..5`、分卷单位在 `0..2`、恢复记录在 `0..100`、已有文件模式在 `0..2`；级别 `0`（仅存储）强制关闭固实压缩；非正或非有限 `MaxSizeGB` 回退 `666`；JSON 损坏或缺失时安全返回 `null`。

### 2. 接入 [MainWindowViewModel.cs](file:///Users/x/code/compress/ViewModels/MainWindowViewModel.cs) 与 [MainWindowViewModel.Lifecycle.cs](file:///Users/x/code/compress/ViewModels/MainWindowViewModel.Lifecycle.cs)

- 构造函数支持注入 `UserPreferencesService?`；设计器模式（`Design.IsDesignMode`）跳过读写。
- **命令行 `--lang` 优先**：初始化语言遵循 `LocalizationService.Instance.LanguageExplicitlySet` > 本地偏好保存语言 > 系统区域性检测；若本次通过 `--lang` 临时启动且用户未在界面手动切换语言，退出时不覆盖原保存的语言偏好。
- 通过 `ApplySavedPreferences` 与 `_isApplyingSavedPreferences` / `_isSwitchingOperationTab` 守护恢复压缩/解压双页签参数与当前操作页签，避免触发 `MVVMTK0034` 警告或误写 `7z` 提醒、`SolidDisabledForStore` 日志。
- 在 `Dispose()` 退订事件和释放文件日志器前调用 `SaveUserPreferences()`。
