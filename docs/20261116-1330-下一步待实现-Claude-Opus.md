## 三、需要用户拍板后才动工（完整说明见主报告第六节）

1. **Windows 产物要不要随包带 7-Zip 程序** —— 现在 Windows 包不含归档器，功能依赖用户预装到特定路径，
   本机测试一条都覆盖不到。选项：随包带 / 放宽查找并给可操作提示 / 只补结构自检。推荐「放宽查找 + 结构自检」。
2. **命令行 `--shutdown` 要不要真的关机** —— 现在只写日志、不执行，帮助里却承诺会关机。
   选项：真正执行 / 显式拒绝并改帮助 / 加二次确认开关。推荐「显式拒绝」，因为三平台关机命令本机验证不了。
3. **图形界面与命令行的默认参数要不要统一** —— 压缩级别、恢复记录、分卷三处都不同。
   选项：统一到一处默认值 / 保持差异但补对照表 / 两边都改为显式必填。推荐「先补对照表，再单独版本统一」。

## 四、需要另外两台机器才能确认（不是本机待办）

- Windows 上 `WinExe` 是否真的导致命令行输出不可见；
- Windows / Linux 打包产物实际能否启动、随包二进制权限是否正确；
- Windows 日志文件的访问控制、Linux 大小写敏感文件系统下的去重口径；
- 退出码 1（警告）在「处理后删除源文件」开启时会不会造成源文件丢失；
- RAR 在 Linux/macOS 对 `-IBCK`/`-SCf` 开关的兼容性。

按项目定位，本机验证即交付依据；这些不列为交付门禁。
