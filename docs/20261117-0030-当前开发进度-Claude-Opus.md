| 改动 | 结果 |

1. **关窗确认长任务还没有鼠标级人工验收**：代码路径、完成信号、源码守护已覆盖；下次在界面上用大目录实际点一次“关闭 → 退出”，确认无临时目录和子进程残留。
2. **覆盖替换只做了常规路径**：多卷命名复用现有解析；进程强杀后的启动恢复扫描尚未单独实现，残留在下一次覆盖前会用备份判断处理。

4. 2150 分析里的 Windows 命令行、当前目录 7-Zip、诊断版本、TXT 缺失项、Linux 关机仍未处理。
