## 四、注意事项

1. **测试与脚本里不要硬编码旧 TFM 路径**：`verify.sh` 已改；以后升级目标框架时要同步搜索 `net10.0`/`net11.0`。
2. **不要用 `NoWarn` 掩盖 NU1510**：.NET 11 共享框架自带 `Logging.Abstractions`，移除显式引用即可。
3. **Avalonia 仍用 net10 资产**：Avalonia 12.1.6 的 NuGet 资产包含 `net10.0`/`net8.0`，net11 项目会选用 net10 资产，实测兼容；没有升级 Avalonia 版本。
4. **Windows / Linux 未实机跑 .NET 11**：三平台云端工作流会在下一次推送时用 .NET 11 构建，仅供参考；按项目定位，本机 macOS 验证即交付依据。
