## 三、需要实机确认（不是本机待办）

1. **Windows 命令行输出可见性**：`WinExe` 配置事实确定，具体是否丢标准输出需在 Windows 命令提示符与重定向下各试一次。
2. **Windows 自动安装 7-Zip**：MSI 管理式解包与 EXE 静默安装哪条可用、企业策略是否拦截。
3. **macOS 真实关机**：命令构造有单元测试，真实执行与自动化授权需用户方便时验证。
4. Windows / Linux 打包产物能否启动、随包二进制权限；退出码 1 与删除源文件的组合；RAR 在 Linux/macOS 的开关兼容性。
