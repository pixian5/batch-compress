## 一、交付内容

### 1. 新增 `Core/Services/WindowStateService.cs`

- `WindowStateSnapshot(Width, Height, X, Y, IsMaximized)` + `Load()` / `Save()`。
- **刻意不引用 Avalonia 类型**，便于单独测试；视图只负责采集当前尺寸与位置。
- **设置文件路径与 JSON 字段完全保持原样**（`Width` / `Height` / `X` / `Y` / `WindowState`，

  升级后不会丢用户已保存的窗口位置。
- 读取失败、文件不存在、JSON 损坏一律返回 `null`；保存失败静默忽略，绝不阻塞退出。

  `MainWindowViewModel.IsMaximized`；按钮文案由 ViewModel 的 `ZoomButtonText` 提供，
  语言切换时也会刷新。
- **代码隐藏 789 → 732 行**。

## 二、关于「代码隐藏降到 450 行」这个目标

**没有达到，实际是 732 行。** 原因不是没抽，而是文件里剩余部分基本是纯视图职责：

- 文件/目录选择器（`StorageProvider`，必须依赖窗口）；
- 消息框与确认对话框；
- 拖放数据解析、源清单高亮与滚动；
- `PathsMatch` 这类 UI 辅助。

继续硬拆只能把这些逻辑包一层再转回去，可读性反而变差。所以本轮按「视图只做视图的事」
的边界停下：窗口状态持久化已完全移出，缩放状态已移入 ViewModel。
如果后续确实需要进一步变薄，建议单独做「对话框服务化」，而不是在这批里混做。
