## 二、任务 1：执行中关窗保护

### 2.1 行为

- 执行中关闭窗口不再直接退出：先取消默认关闭，弹程序内确认框；
- “继续”：任务继续，不释放任何资源；
- “退出”：调用现有取消命令，等待 `OperationSession` 的 `finally` 真正执行完，最多 10 秒；
- 超时：再弹一次“清理尚未完成，仍要强制退出吗？”；
- 只有真正关闭时才释放 ViewModel 与文件日志器，避免日志器提前释放；
- 托盘“退出”改为走 `window.Close()`，不再用 `desktop.Shutdown()` 绕过保护；窗口隐藏且正在执行时先显示，保证确认框有可见 owner；
- 新增 7 个五语言词条（标题、正文、退出、继续、超时标题、超时正文、强制退出），五份 JSON 从 350 增至 **357 键**。

### 2.2 实现位置

- `ViewModels/OperationCompletionSignal.cs`：纯类，负责开始/完成/等待；可单测，避免只等一个布尔值。
- `ViewModels/MainWindowViewModel.Lifecycle.cs`：`OnIsOperatingChanged` 驱动信号，暴露 `WaitForOperationCompletionAsync()`。
- `Views/MainWindow.axaml.cs`：`MainWindow_Closing` 拦截、`CompleteClose()`、`ConfirmCloseDuringOperationAsync()`；复用已有 `ShowOkCancelMessageBoxAsync`，并给消息文本加自动换行。
- `App.axaml.cs`：托盘退出走窗口关闭路径。

### 2.3 测试

- 新增“操作完成信号”测试：无操作立即完成、开始后不提前完成、完成后唤醒、第二次操作使用新任务。
- 源码守护：检查 `e.Cancel = true`、`CancelOperationCommand.Execute`、`WaitForOperationCompletionAsync`、`ConfirmCloseDuringOperationAsync`、托盘 `window.Close()` 均存在。
- **未完成的人工验证**：长任务中真实点击关闭 → 确认 → 观察临时目录/子进程，需要下次在界面上手动走一遍；当前代码路径与信号已由单元测试/源码守护覆盖，但界面按钮自动化不可靠，本轮没有做鼠标级实测。

## 三、任务 2：覆盖写入先临时后替换

### 3.1 行为

- 准备阶段不再删除旧归档；
- 执行前把已存在的输出卷改名为 `<原名>.batchcompress-backup`；
- 压缩成功后删除备份；失败或取消时先清理本次新写的最终卷，再把备份改回原名；
- 上次成功但删除备份失败留下的旧备份，会在下一次覆盖前按时间判断：最终文件更新则删备份，否则用备份恢复；
- 旧文件恢复后重新纳入“原有文件”保护，避免管线随后调用失败清理时把它们当成本次残片删掉。

### 3.2 测试

- 新增“覆盖失败保留旧归档”：旧 `source.txt.7z` 内容为 `old archive`，假引擎写一半失败后：
  - 旧文件仍存在且内容不变；
  - 新生成的 `.001`/`.002` 被清理；
  - 不残留 `.batchcompress-backup`。
- 原有“覆盖成功删除旧主卷、part 分卷、`.r00` 遗留”测试继续通过。

### 3.3 范围说明

本批只覆盖常规路径；多卷命名映射在现有 `ArchiveVolumeResolver` 基础上复用，但“进程被强杀后的自动恢复”只做了下一次覆盖前的备份判断，没有做独立的启动恢复扫描。后续可拆出 `OutputReplacementRecovery`。

## 四、任务 3：目录大小排除符号链接

### 4.1 行为

- 新增 `Core/Services/DirectorySizeCalculator.cs`，返回字节数与逐项错误；
- 使用 `EnumerationOptions`：递归、忽略无权限目录、`AttributesToSkip = ReparsePoint`；
- 界面总大小计算改为调用它，不再用 `Directory.GetFiles(..., AllDirectories)`；
- `SystemMetadataFileFilter` 继续过滤 `.DS_Store`、`Thumbs.db` 等。

### 4.2 测试

- 普通目录：3 字节 + 5 字节 = 8 字节；
- 在根目录创建指向自身的符号链接，结果仍为 8 字节、无错误；
- 测试结束先删链接再删根目录，避免误删目标。
