- **现状**：`Microsoft.Extensions.Logging`、`.Console`、`System.Resources.Extensions`
  均有 `10.0.14 → 11.0.0`。
- **做法**：
  1. 先读 11.0 的破坏性变更说明（API、默认格式、作用域行为）；
  2. 单独升级三个包，不夹带其它改动；
  3. 重点验证：日志文件格式、多代轮转（`.1` 纯文本 / `.2+` Gzip）、0600 权限、
     保留期清理、诊断导出能解包 `.gz`、`ILogger` 注入链无变化；
  4. 若与 Avalonia 12.1.6 依赖树冲突，保留 10.0.14 并在报告写明原因。
- **验收**：上述六项全过 + 78 项测试 + 21 项实测 + 149 项夹具 + 3 项界面冒烟。
