## 代码与脚本改动

### 1. 按卷大小写敏感检测与跨卷预检修复

- [BatchPreflightService.cs](file:///Users/x/code/compress/Core/Services/BatchPreflightService.cs#L242-L370)：
  - `FileSystemPathIdentity` 新增 `IsCaseSensitive(string? path)`，带最近存在目录向上解析与 256 项并发缓存：
    - macOS 通过 `libSystem.dylib` 调用 `pathconf(probeDir, _PC_CASE_SENSITIVE /* 11 */)` 直接向 APFS/HFS+ 查询当前卷真实能力；
    - Windows 返回 `false`；
    - Linux 通过只读无副作用探测兼容外接不区分大小写挂载卷。
  - `GetComparer(path)` 与 `IsSameOrDescendant` 均切换为调用 `IsCaseSensitive`。
- [BatchPreflightService.cs](file:///Users/x/code/compress/Core/Services/BatchPreflightService.cs#L183-L216)：
  - 真实 `Case-sensitive APFS` 实测暴露了 `AddDuplicateOutputConflicts` 使用 `Directory.GetCurrentDirectory()` 比较目标路径导致大小写不同归档被误判冲突的隐藏缺陷；已改为按目标路径所在卷分别比较的 `VolumeAwarePathComparer`。
