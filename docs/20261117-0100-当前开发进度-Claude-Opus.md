## 四、注意事项

1. **7-Zip 自定义路径改成显式环境变量**：`BATCHCOMPRESS_7ZZ_PATH`；程序目录与系统路径仍是默认候选，正常打包运行不受影响。
2. **脱敏规则现在只有一处**：以后改规则只改 `CredentialRedactor`，并同时跑诊断、报告、NDJSON 的测试。
3. **“随机密码”只是改文案**：派生算法没变，旧归档密码查询结果不变；真正随机密码需要另做显式模式。
4. Windows 日志 ACL 未实机验证；Windows 命令行、诊断包 `AppVersion=unknown`、TXT 清单缺失项、Linux 关机权限仍未处理。
