## 一、这一版做了什么

用户授权自行决定，按本机可闭环的优先级完成四项可靠性收尾：

| 改动 | 结果 |
| --- | --- |
| 诊断包版本 | 改用程序集版本；打包应用 `AppVersion=0.8.17`，不再是 `unknown` |
| 命令行 TXT 缺失项 | 缺失/缺卷/歧义/重复卷条目进入任务计数；完全不存在按 `NotFound` 计 |
| 覆盖备份恢复 | 新增 `OutputBackupRecovery`，进程强杀后下一次进入输出目录自动恢复/清理 |
| 报告原子写入 | 临时文件 + 原子替换，避免半截 CSV/Markdown |
| 版本 | `0.8.16` → **`0.8.17`** |

详细说明见 [本机可靠性收尾完成报告](20261117-0920-本机可靠性收尾完成报告-Claude-Opus.md)。

## 四、注意事项

1. **完全缺失归档现在按 `NotFound` 计**：0.8.17 在解析分卷前先判断“文件不存在且没有同组分卷”；有同组残卷仍按 `IncompleteVolumes` 计。相关本地化测试已从“缺首卷”改为“缺失归档”。
2. **备份恢复是尽力而为**：单个备份恢复失败不会阻止后续条目，下一次覆盖前仍会重试。
3. **TXT 清单仍按“文件名 / 密码”交替读取**：缺失项也要占一行密码位置，否则下一项会被当成密码。
4. 长任务关窗的鼠标级人工验收仍未做；Windows/Linux 真机项按要求暂停。
