# v0.8.23 数据安全加固完成报告

> 用户原问题：继续  
> 版本：`0.8.22 → 0.8.23`　时间：2026-11-26 14:04　模型：Gemini 4 Neon

## 背景与目标

基于 `0.8.22` 整体分析中列出的 **批次 34（P1 数据安全加固）**，本轮完成两项安全保护改进与配套回归测试：

1. 解压失败回滚输出目录快照改用平台感知的大小写比较，防止 macOS / Windows 大小写不敏感文件系统下误删已有文件。
2. 图形界面勾选“删除源”时增加二次确认弹窗，防止用户误触永久删除源文件或原归档；命令行 `--delete-source` 保持不变。

## 代码改动

### 1. 解压失败回滚大小写保护

- [DecompressionItemAdapter.cs](file:///Users/x/code/compress/Core/Services/Pipeline/DecompressionItemAdapter.cs#L307-L325)：`SnapshotOutputDirectory` 中的 `HashSet<string>` 由 `StringComparer.Ordinal` 改为 `FileSystemPathIdentity.GetComparer(outputDirectory)`（macOS 与 Windows 使用 `OrdinalIgnoreCase`，Linux 保留 `Ordinal`）。
- 当输出目录原有 `readme.txt`，而失败归档在 macOS / Windows 上写出 `Readme.txt` 时，回滚清理不再把它误判为本次新增文件而删掉原文件。

### 2. 界面“删除源”勾选框二次确认

- 新增 [DeleteSourceConfirmationGuard.cs](file:///Users/x/code/compress/ViewModels/DeleteSourceConfirmationGuard.cs) 并接入测试工程 [BatchCompress.Avalonia.Tests.csproj](file:///Users/x/code/compress/BatchCompress.Avalonia.Tests/BatchCompress.Avalonia.Tests.csproj)：管理确认状态 `_isConfirming`（防重入、异常安全复位、无回调时透传兼容无头/设计器）。
- [MainWindowViewModel.cs](file:///Users/x/code/compress/ViewModels/MainWindowViewModel.cs)：新增 `ConfirmDeleteSourceRequested` 回调与 `ConfirmDeleteSourceAfterAsync()`。用户在压缩/解压页勾选 `DeleteSourceAfter` 时弹出确认框；取消确认或发生异常时自动回退 `DeleteSourceAfter = false`，仅确认后才互斥关闭 `MoveSourceAfter`。切换页签加载状态期间不重复弹窗。
- [MainWindow.axaml.cs](file:///Users/x/code/compress/Views/MainWindow.axaml.cs)：在 `OnDataContextChanged` 注入 `ConfirmDeleteSourceAsync`，复用 `ShowOkCancelMessageBoxAsync` 弹窗提示删除不可逆。
- [LanguageStrings.cs](file:///Users/x/code/compress/Localization/LanguageStrings.cs) 与 `Localization/Resources/{zh-CN,zh-TW,en,ja,de}.json`：五语言同步新增 `ConfirmDeleteSourceTitle`、`ConfirmDeleteSourceBody`、`ConfirmDeleteSourceEnable`（共 360 键）。
