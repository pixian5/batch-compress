## 二、P4-1　多卷解压损坏即时拦截

- **现状**：批次 17 已把 `7zz -bsp1` 的逐行进度流接到 `ArchiveSubProgressParser`，
  但解析器只提取百分比与分卷序号，遇到坏块（CRC Error）仍会跑完整个归档才报错。
- **目标**：在解压超大多卷分卷时，从流里捕获明确的致命错误并提前终止该归档，
  记录精准定位，减少无效磁盘读取。
- **改动点**：`ArchiveSubProgressParser` 增加「致命错误」识别（只认明确的
  `CRC Error` / `Data Error` / `Unexpected end of archive` / `Can not open file as archive` 等，
  不认普通警告）；`ArchiveProcessRunner` 的行回调把错误信号传给调用方；
  `BatchExecutionPipeline` 据此取消**当前**任务而非整批，并走既有 `OnExecutionFailed` 回滚。
- **验收**：构造一个故意损坏的分卷，观察任务提前结束、输出目录零残片、日志定位到具体卷；
  正常归档零误杀；72 项测试 + 18 项实测 + 149 项夹具不回归。
- **风险**：误判会中断正常任务，必须先写「不该被当成致命错误」的白名单断言；
  解析器失败要降级为「不提前终止」，绝不能因解析异常影响归档结果。
- **版本**：改产品源码，`+0.0.1`。

## 三、P4-3　多任务历史导出与审计报告

- **现状**：界面有源列表/成功/失败/命令日志四类记录，但只能在窗口里看，不能导出。
- **目标**：把本次批处理的详细执行清单导出为 CSV（逗号分隔值）或 Markdown 汇总表，
  便于留档与问题复盘。
- **改动点**：在 `OperationProgressInfo` / 会话里累积逐项结果；
  新建导出服务（复用批次 16 的 `DiagnosticsExportService` 打包经验）；
  界面加「导出结果」按钮与五语言词条；CLI 可考虑 `--output-format json` 之外提供 `--report <path>`。
- **验收**：导出文件含每条任务的来源、结果、耗时、字节数；
  **不得包含明文密码**（与诊断导出不同，结果报告默认不含原始命令行）；
  五语言界面文案齐全。
- **风险**：报告里若混入命令日志会泄露密码，必须走独立字段而非复用命令日志文本。
- **版本**：改产品源码，`+0.0.1`。

## 四、把 149 项端到端夹具接入持续集成（建议优先做）

- **现状**：`测试夹具/全功能测试/run-all-tests.sh` 本机实测 `TOTAL PASS=149 FAIL=0`，
  但 `ci.yml` / `release.yml` 都没有调用它。本轮还发现它**必须用 zsh 运行**：
  脚本用 `${0:A:h:h:h}` 与 `print`，用 `bash` 调用会报 `print: command not found`
  且路径解析成根目录。
- **改动点**：在 `ci.yml` 的 macOS 作业（或独立作业）里显式用
  `zsh 测试夹具/全功能测试/run-all-tests.sh` 调用，并把输出作为门禁；
  在脚本头部加一句注释写明「必须用 zsh」；`release.yml` 的测试门禁复用。
- **验收**：故意破坏一个夹具断言，CI 必须红；正常提交全绿。
- **风险**：夹具依赖真实 `7zz` 与本机路径，跨平台要确认；至少先在 macOS runner 落地。
- **版本**：仅工作流改动，不加版本。

## 五、需要你拍板的两件事（沿用上一轮，仍未收到决定）

**1. macOS 正式签名与公证。**
现状：`package-macos.sh` 支持注入证书做硬化运行时签名，但无证书时是临时签名；
本轮实测安装后的应用能启动，脚本也打印了 Gatekeeper（系统门禁）绕过指引。
不改的后果：别人从发布页下载会被系统拦截，macOS 分发实质只对开发者可用。
选项：① 接入 Apple Developer 账号（年费）＋开发者证书＋公证；
② 维持临时签名并在发布说明写清绕过方法；③ 暂不分发 macOS 包。
**推荐 ①**，流水线已齐，只差证书与公证步骤；不想投入就先落实 ②。

**2. RAR 随 Linux 产物分发。**
现状：`--no-rar` 纯净版已可构建，完整版仍随 `linux-x64` 产物发布。
选项：① 做一次许可复核并把结论写进风险文档；② 把纯净版设为默认、
完整版作为可选附件；③ 完全不随产物分发 RAR。**推荐 ②**，兼顾开箱即用与合规保险。
