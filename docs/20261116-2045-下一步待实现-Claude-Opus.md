## 三、本版新增的两个「待实机确认」（不是本机待办）

1. **Windows 自动安装 7-Zip 的完整流程**：MSI 管理式解包与 EXE 静默安装哪条在真实 Windows 上可用、企业策略是否拦截、普通用户目录写权限是否足够。本机只验证了下载地址解析、SHA-256 校验、安装布局归位与身份校验，**没有 Windows 机器可运行**。
2. **macOS 真实关机**：命令构造由单元测试守护，但为了避免关掉开发机，没有实际执行。首次使用会请求自动化授权（`Info.plist` 已写用途说明），允许后才会关机。

另外仍需要另两台机器确认的旧项：

- Windows 上 `WinExe` 是否导致命令行输出不可见（配置事实确定，表现待实机）；
- Windows / Linux 打包产物能否实际启动、随包二进制权限是否正确；
- Windows 日志文件访问控制、Linux 大小写敏感文件系统下的去重口径；
- 退出码 1（警告）在「处理后删除源文件」开启时会不会造成源文件丢失；
- RAR 在 Linux/macOS 对 `-IBCK`/`-SCf` 开关的兼容性。

按项目定位，本机验证即交付依据；这些不列为交付门禁。
