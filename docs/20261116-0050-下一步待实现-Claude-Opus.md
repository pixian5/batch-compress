## 批次 24（下一批，P2）本地化资源外置

- **现状**：`LocalizationService.cs` 1,752 行，五种语言各一个约 290 行的 `Create*()` 方法；
  `LanguageStrings.cs` 364 行属性类。
- **设计**：五份 `Localization/Resources/{zh-CN,zh-TW,en,ja,de}.json` + `LocalizationLoader`
  反射赋值；`LanguageStrings` 保留为强类型访问层与缺键兜底。
- **迁移五步**：导出 JSON 并人工校对 → 换加载器 → 锁五份键集合与属性集合一致 →
  删五个 `Create*()` → 删临时导出命令。
- **验收**：76 项测试全过（尤其「英文与德语资源不含中文」「界面本地化资源扫描」）；
  五语言界面人工各看一遍无空词条；新增测试语言只需加一份 JSON。
- **风险**：反射赋值拼错属性名会静默失效，键集合测试必须先落地；
  迁移期保留一版内置字典作为回退。
- **版本**：改产品源码，`+0.0.1` → `0.8.7`。
