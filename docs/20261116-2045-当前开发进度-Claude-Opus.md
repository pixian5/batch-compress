## 一、这一版做了什么

`0.8.12` 是用户三项决定的落地版本，三项都属于行为变化，不是内部重构：

| 决定 | 落地结果 |
| --- | --- |
| Windows 不随包带 7-Zip，没有就自动从官网下载安装 | 新增自动准备服务；装在当前用户目录，优先校验官方 SHA-256，MSI 解包失败退回 EXE 静默安装，不请求管理员权限 |
| 命令行的自动关机开关要真的关机 | 新增跨平台关机服务，命令行与界面共用；Windows/Linux 保留一分钟延迟，macOS 走 AppleScript |
| 图形界面与命令行的默认参数要统一 | 统一为标准压缩、3% 恢复记录、默认不分卷；唯一来源 `ArchiveDefaults`，界面页签状态里的旧值一并改掉 |

详细实现、验证证据、风险与回滚见 [批次 28 完成报告](20261116-2045-批次28完成报告-Claude-Opus.md)。

## 三、行为变化（升级时要知道）

1. **图形界面默认值变了**：压缩率从「最快」变成「标准」，恢复记录从 0 变成 3%，分卷从「开启 20 GB」变成「关闭」。这是用户明确要求的统一；命令行原本就是这组值，所以命令行默认行为不变。
2. **Windows 首次真实执行会联网**：如果系统里找不到 7-Zip，会从官方渠道下载约 2 MB 的安装包并安装到 `%LOCALAPPDATA%\BatchCompress\7zip`。试运行（`--dry-run`）不会触发下载。
3. **命令行 `--shutdown` 会真的关机**：Windows/Linux 提交一分钟延迟的关机请求；macOS 首次会弹一次自动化授权，允许后才会执行。
4. **macOS 应用包新增自动化用途说明**：`Info.plist` 增加 `NSAppleEventsUsageDescription`，用于「完成后关机」。

## 四、依赖与平台状态

- macOS：随包官方 7-Zip 26.05 universal `7zz`，本机验证全部通过。
- Linux：随包官方 7-Zip 26.05 x64 / ARM64 `7zz`，本机未运行（无 Linux 机器）。
- Windows：**不再随包 7-Zip**，改为首次运行时自动下载安装；本机无 Windows，安装流程只做了纯逻辑测试，需实机确认。
- RAR：仍需用户自行安装 WinRAR / RAR；创建 RAR 只能靠 `rar`。

## 五、仍然存在的风险

- Windows 自动安装未实机验证：最可能出问题的是企业策略拒绝 MSI 管理式解包；已保留 EXE 静默安装后备与手动安装提示。
- macOS 真实关机未实测（避免关掉开发机）：命令构造由单元测试守护，首次授权行为需用户实际使用确认。
- 其余缺陷与验证链盲区仍在，见 [下一步待实现](20261116-2045-下一步待实现-Claude-Opus.md)。
