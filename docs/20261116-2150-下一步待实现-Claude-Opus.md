四批缺陷修完后，项目已进入“功能基本齐、边界要压实”的阶段。下一步不建议继续加功能或大重构，优先做三件事：

1. **运行中关窗不能直接杀进程**——避免半成品归档、临时目录和孤儿压缩进程；

3. **安全边界收口**——不让程序执行当前目录里的伪造 7-Zip，统一报告/JSON 的密码兜底。

## 三、需要你拍板的三件事（详细说明在报告第六节）

1. **Windows 命令行输出方式**
   - 拆两个程序（图形 + 命令行）：最干净，工作量最大；
   - 单个控制台程序 + 隐藏控制台窗口：命令行最可靠，双击时可能闪窗；
   - 保持图形程序 + 附加父控制台：改动最小，但重定向/无控制台场景不一定可用。
   - 推荐：先做“控制台程序 + 隐藏窗口”的 Windows 试验，不行再拆两个程序。

2. **“随机密码”要不要变成真随机**
   - 现在实际是按文件名算出的固定密码，不是随机；
   - 推荐先改文案为“按文件名生成密码”并说明不是密码学保护；
   - 如确需真加密，再新增显式的密码学随机模式，默认不悄悄改变旧行为。

3. **任务执行中关闭窗口**
   - 阻止关闭 / 确认后取消并等待清理 / 继续强制退出；
   - 推荐确认后取消并等待，超时再询问是否强制退出。
