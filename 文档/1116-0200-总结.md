## 一、结论：升级通过，已采用 11.0.0

三个产品依赖与测试工程的日志抽象包全部从 `10.0.14` 升到 `11.0.0`。**版本没有递增**——本批只改依赖版本，没有修改产品源码，按项目约定不触发加版本。

**为什么可以升**：

- 11.0.0 包提供 `net10.0` 资产，还原与全量重编译都是 0 警告 0 错误；官方记录的破坏性变更主要针对 `net11.0` 及以上目标框架（九个扩展库进共享框架、显式引用会报 NU1510）和日志库作者（内部类型迁移、兼容垫片标记过期），本项目的 `net10.0` 目标框架和「自己实现 ILogger / ILoggerProvider 稳定接口」的写法都不受影响。
- Avalonia 12.1.6 的依赖树不引用 Microsoft.Extensions.*，没有出现设计方案里担心的冲突。
- 传递依赖会整体升到 11.0.0（含 System.Text.Json 等基础库），实际打进发布输入的程序集版本实测为 `11.0.0.0`；真实界面启动后窗口标题正常，说明五语言本地化资源在 11.0 的 JSON 库下加载无误。
