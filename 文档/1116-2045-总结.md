## 一句话结论

三项决定全部落地：Windows 改为运行时自动下载安装 7-Zip；命令行 `--shutdown` 真正调用系统关机；两个入口的默认压缩参数统一到「标准压缩、3% 恢复记录、不分卷」。92 项测试、37 项实测、149 项夹具、4 条界面冒烟、交付冒烟全过，本机打包启动 `v0.8.12`。

## 三项改动的结果

### 1. Windows 不随包带 7-Zip，缺失时自动安装

- 安装位置固定在当前用户目录 `%LOCALAPPDATA%\BatchCompress\7zip`，**不需要管理员权限**，不写系统目录、不改环境变量。
- 下载优先走 7-Zip 官方 GitHub 发布接口，那里同时给出 SHA-256；校验不通过直接拒绝。接口不可用时退回官方下载页，日志会注明「仅依赖 HTTPS」。
- 先尝试 MSI 管理式解包（只展开文件、不注册组件），失败再退回 EXE 静默安装；两条路都不会弹安装界面。
- 安装后执行一次 `7z.exe i` 做身份校验，并确认 `7z.dll` 存在——WIM 等格式依赖它，不能等到跑任务才发现缺文件。
- 界面在窗口显示后后台检查，点击压缩/解压前再确保一次；命令行在参数校验与试运行判断之后检查，下载进度写标准错误，不污染结构化输出。
- **本机没有 Windows，安装流程只做了纯逻辑测试**（地址解析、校验和、目录归位、入口接线），实际能否安装成功需要 Windows 实机确认。

### 2. 命令行 `--shutdown` 真正关机

- 新增跨平台关机服务，命令行与界面共用：
  - Windows `shutdown /s /t 60`，取消 `shutdown /a`；
  - Linux `shutdown -h +1`，取消 `shutdown -c`；
  - macOS 改走 AppleScript，延迟 60 秒后请求 System Events 关机，取消时结束待执行的脚本进程。
- macOS 原来的 `/sbin/shutdown` 需要 root，普通用户会直接失败；这是顺带修掉的一个真实问题。
- 应用包 `Info.plist` 增加 `NSAppleEventsUsageDescription`，否则系统无法弹出自动化授权提示。
- **没有在本机执行真实关机**（会关掉开发机）；命令构造由单元测试守护，真实行为需要你在方便时验证一次，首次会请求自动化授权。

### 3. 两个入口默认参数统一

| 参数 | 统一前（界面 / 命令行） | 统一后 |
| --- | --- | --- |
| 压缩级别 | 最快 / 标准 | **标准（3）** |
| 恢复记录 | 0 / 3% | **3%** |
| 分卷 | 开启、20 GB / 不分卷 | **不分卷** |

唯一来源是 `ArchiveDefaults` 里的常量。这里有一个容易漏的点：界面除字段初值外，页签状态类里还藏着一套旧默认值，切换页签会把它覆盖回来；这次一并改掉，并加了源码守护测试。界面启动时把实际默认值写进运行日志，实测为 `level=3, recovery=3%, volume=none`。
